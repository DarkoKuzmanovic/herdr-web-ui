# herdr-hermes-state

Hermes plugin that reports Hermes's state (working / idle / blocked on a question) to the Herdr pane it runs in, so the web UI shows answer cards and sends "needs input" alerts.

Install: `ln -s ~/code/herdr-web-ui/hermes-plugin ~/.hermes/plugins/herdr-hermes-state && hermes plugins enable herdr-hermes-state`, then start a new Hermes session.
